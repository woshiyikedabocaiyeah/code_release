# Large files not stored in Git

The following generated archives and model weight are intentionally excluded
because each file is larger than GitHub's supported per-file limit:

- `feature_score_extraction.zip`
- `feature_score_extraction/checkpoints.zip`
- `feature_score_extraction/checkpoints/vith.pt`

The source code contained by the archives is present directly under this
directory. Download or regenerate the model checkpoint separately before
running workflows that require it.
